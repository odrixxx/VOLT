# 🤖 Мой первый Telegram-бот (этап 1: только приветствие)

**Что умеет бот прямо сейчас:** он делает ровно одну вещь — при **первом
взаимодействии** пользователя отправляет приветствие акции VOLT: **картинку
с текстом-подписью**. Всё. Никаких других команд, кнопок и функций пока нет —
добавим позже.

---

## 📁 Структура проекта

| Файл | Для чего |
|---|---|
| `bot.py` | Главный файл. Создаёт бота и запускает его. **Запускать нужно именно его.** |
| `handlers.py` | «Мозги» бота: здесь живёт логика приветствия (3 маленьких хэндлера). |
| `welcome.png` | Картинка, которую бот прикрепляет к приветствию. Кладётся прямо в корень проекта, рядом с `bot.py` (можно jpg/jpeg/png)! |
| `requirements.txt` | Список библиотек, которые нужно установить. |
| `.env.example` | Образец файла с токеном. Его копируем в `.env`. |
| `.gitignore` | Говорит Git'у игнорировать `.env` и `venv/`, чтобы токен не попал в интернет. |

### 🖼️ Как поменять картинку приветствия
1. Найди/сделай свою картинку (подойдёт jpg, jpeg или png; Telegram любит файлы до ~10 МБ).
2. Сохрани её **в корень проекта** (рядом с `bot.py`) с именем `welcome.png` — либо `welcome.jpg` / `welcome.jpeg`, бот найдёт любой из этих вариантов.
3. Перезапусти бота (`Ctrl+C`, затем `python bot.py`). Всё — новая картинка в приветствии.
4. Если картинки нет вообще, бот не упадёт: он начнёт присылать просто текст.

## Шаг 0. Что нужно установить на компьютер

1. **Python 3.10 или новее** — скачай с https://python.org (Windows: поставь
   галочку **"Add Python to PATH"** при установке!).
   Проверка: открой терминал и напиши `python --version` (на Mac/Linux иногда
   `python3 --version`).
2. **Терминал**: Windows — "Командная строка" или PowerShell; Mac — Terminal.

## Шаг 1. Создай бота и получи токен 🔑

Токен — это «пароль», дающий программе право писать от имени твоего бота.

1. Открой Telegram, найди **@BotFather** (официальный бот для создания ботов).
2. Отправь ему команду `/newbot`.
3. Придумай **имя** бота (любое, например «Мой тестовый бот»).
4. Придумай **username** — обязательно заканчивается на `bot`
   (например `my_test_123_bot`).
5. BotFather пришлёт токен вида `123456789:AAHxp...` — **скопируй его целиком**.

> ⚠️ Никому не показывай токен! Тот, у кого он есть, управляет твоим ботом.
> Если токен засветился — у @BotFather команда `/revoke` создаст новый.

## Шаг 2. Настрой проект у себя на компьютере

Открой терминал и переходи в папку проекта:

```bash
cd путь/до/папки/проекта
```

### 2.1. Виртуальное окружение (venv) — «изолированная песочница» для библиотек

Зачем: чтобы библиотеки этого проекта не мешали другим твоим проектам.

```bash
# Windows:
python -m venv venv
venv\Scripts\activate

# Mac / Linux:
python3 -m venv venv
source venv/bin/activate
```

Получилось? В начале строки терминала появилось `(venv)` — значит ты внутри
песочницы. (Выйти из неё когда захочешь: команда `deactivate`.)

### 2.2. Установка библиотек

```bash
pip install -r requirements.txt
```

Устанавливаются две библиотеки:
* **aiogram** — библиотека, которая умеет разговаривать с Telegram API;
* **python-dotenv** — маленькая помощница, читающая токен из файла `.env`.

### 2.3. Файл .env — куда положить токен

Создай в папке проекта файл с именем `.env` (с точкой в начале!) и впиши туда
одну строку, подставив свой токен:

```
TELEGRAM_BOT_TOKEN=123456789:AAHxp_твой_настоящий_токен
```

Как создать файл:
* **VS Code**: правый клик в проекте → New File → имя `.env` → вставить строку → Ctrl+S.
* **Терминал (Windows)**: `notepad .env`
* **Терминал (Mac/Linux)**: `nano .env`, затем Ctrl+O, Enter, Ctrl+X.

> Почему не вписать токен прямо в код? Чтобы при публикации кода секрет не уехал
> в интернет. `.env` мы спрятали через `.gitignore`.

## Шаг 3. Запуск 🚀

```bash
python bot.py
```

Если всё сделано правильно, в терминале появится:

```
✅ Бот запущен и ждёт сообщений. Нажми Ctrl+C, чтобы остановить.
```

Теперь открой чат со своим ботом в Telegram и напиши ему что угодно.

## Шаг 4. Как проверить, что работает ✅

| Действие в Telegram | Ожидаемая реакция бота |
|---|---|
| Первое сообщение (или `/start`) | ⚡️👋 Приветствие VOLT («ДОБРО ПОЖАЛОВАТЬ В КОМАНДУ VOLT!» + текст акции, имя подставляется автоматически) |
| Любые следующие сообщения | **Тишина** — бот молчит, он умеет только здороваться |
| Сообщение от другого человека впервые | Тоже получит приветствие |
| Перезапустить `python bot.py` и написать снова | Снова приветствие (память живёт только пока запущен скрипт) |

## Как это работает (схема)

```
Telegram-серверы ──(polling: бот каждые пару секунд спрашивает "есть новости?")──▶ bot.py
                                                                                     │
                                                                              Dispatcher
                                                                                     │
                                                            handlers.py: проверяет сверху вниз:
                                                            1. /start?      → try_greet()
                                                            2. любой текст? → try_greet()
                                                            3. остальное?   → try_greet()
                                                                                     │
                                                    try_greet(): если ID нет в welcomed_users —
                                                    добавляет и шлёт картинку welcome.png (в корне проекта)
                                                    с текстом-подписью (send_greeting); иначе молчит.
```

## ❓ Частые ошибки новичков

| Текст ошибки | Причина | Решение |
|---|---|---|
| `❌ Токен не найден!` | Нет файла `.env` или там пусто/не заполнен | См. Шаг 2.3 |
| `Unauthorized` | Токен неверный/обрезан/отозван | Скопируй токен целиком; при необходимости `/revoke` у BotFather |
| `pip is not recognized` | Python не добавлен в PATH | Переустанови Python с галочкой "Add Python to PATH" |
| `python3: command not found` (Windows) | На Windows команда обычно `python` | Используй `python` вместо `python3` |
| Бот молчит | Скрипт остановлен в терминале | Снова запусти `python bot.py`; убедись, что активирован `(venv)` |
