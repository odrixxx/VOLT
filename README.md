# 🤖 Telegram-бот акции VOLT: приветствие + приём и проверка чеков

**Что умеет бот прямо сейчас:**
1. При **первом взаимодействии** присылает приветствие акции VOLT (картинка с
   подписью, если `welcome.*` лежит в корне, иначе просто текст) и кнопку
   **«ПОГНАЛИ 🔥»**.
2. По нажатию на кнопку показывает инструкцию «КАК ПОЛУЧИТЬ РОБУКСЫ?» — под ней
   остаётся одна кнопка «ПОГНАЛИ 🔥» (повторное нажатие напоминает прислать фото
   чека всплывающим уведомлением; кнопок «Назад» и «Пополнить через бота» больше нет).
3. Принимает фото чека, **реально распознаёт текст (OCR)** и проверяет: бренд
   «VOLT», дату, сумму, резкость фото и отсутствие дубликата.
4. Выдаёт вердикт: ✅ ЧЕК ПРИНЯТ или ❌ ЧЕК НЕ ПРИНЯТ с конкретной причиной.

## 📁 Структура проекта

| Файл | Для чего |
|---|---|
| `bot.py` | Главный файл. Создаёт бота и запускает его. **Запускать нужно именно его.** |
| `handlers.py` | «Мозги» бота: приветствие, кнопка «ПОГНАЛИ 🔥», приём фото, выдача вердикта. |
| `admin.py` | 🔒 Секретная админ-панель: незаметно пересылает все сообщения пользователей админу и позволяет писать им от имени бота (`/write`, `/talk`). Обычные юзеры о ней не знают. |
| `receipt_check.py` | Реальная проверка чека: резкость, OCR-движки, разбор даты/суммы, поиск «VOLT», защита от дубликатов. |
| `welcome.png` | Картинка, которую бот прикрепляет к приветствию. Кладётся прямо в корень проекта, рядом с `bot.py` (можно jpg/jpeg/png)! |
| `requirements.txt` | Список библиотек, которые нужно установить. |
| `.env.example` | Образец файла с токеном. Его копируем в `.env`. |
| `.gitignore` | Говорит Git'у игнорировать `.env`, `venv/` и папку принятых чеков. |
| `test_receipt_check.py` | Быстрые проверки логики распознавания (`python3 test_receipt_check.py`). |
| `test_bot_flow.py` | Проверка всей цепочки «кнопка → инструкция → фото → вердикт» без Telegram. |
| `test_admin_flow.py` | Проверка админ-панели: зеркало сообщений, `/write`, режим `/talk`, защита от утечек. |
| `accepted_checks/` | Создаётся сама: сюда складываются копии принятых чеков и журнал `accepted_checks.txt`. |

### 🖼️ Как поменять картинку приветствия
1. Найди/сделай свою картинку (подойдёт jpg, jpeg, png, webp, bmp; Telegram любит файлы до ~10 МБ).
2. Просто сохрани её **в корень проекта** (рядом с `bot.py`) — можно **не переименовывать**!
   Бот сам найдёт файл по типичным именам: `welcome.*`, `photo.jpg`, `IMG_1234.PNG`,
   `DSC_0001.JPG`, `Screenshot...`, `mmexport...` и т.п. А если в корне лежит ровно
   одна картинка с любым именем — бот возьмёт её. (Если хочешь гарантированный
   приоритет — назови файл `welcome.png` / `welcome.jpg`.)
3. Перезапусти бота (`Ctrl+C`, затем `python bot.py`). Всё — новая картинка в приветствии.
4. Если картинки нет вообще, бот не упадёт: он начнёт присылать просто текст.

## Шаг 0. Что нужно установить на компьютер

1. **Python 3.10 или новее** — скачай с https://python.org (Windows: поставь
   галочку **"Add Python to PATH"** при установке!).
   Проверка: открой терминал и напиши `python --version` (на Mac/Linux иногда
   `python3 --version`).
2. **Терминал**: Windows — "Командная строка" или PowerShell; Mac — Terminal.

## Шаг 1. Создай бота и получи токен 🔑

Токен — это «пароль», дающий программе право писать от имени твоего бота.

1. Открой Telegram, найди **@BotFather** (официальный бот для создания ботов).
2. Отправь ему команду `/newbot`.
3. Придумай **имя** бота (любое, например «Мой тестовый бот»).
4. Придумай **username** — обязательно заканчивается на `bot`
   (например `my_test_123_bot`).
5. BotFather пришлёт токен вида `123456789:AAHxp...` — **скопируй его целиком**.

> ⚠️ Никому не показывай токен! Тот, у кого он есть, управляет твоим ботом.
> Если токен засветился — у @BotFather команда `/revoke` создаст новый.

## Шаг 2. Настрой проект у себя на компьютере

Открой терминал и переходи в папку проекта:

```bash
cd путь/до/папки/проекта
```

### 2.1. Виртуальное окружение (venv) — «изолированная песочница» для библиотек

Зачем: чтобы библиотеки этого проекта не мешали другим твоим проектам.

```bash
# Windows:
python -m venv venv
venv\Scripts\activate

# Mac / Linux:
python3 -m venv venv
source venv/bin/activate
```

Получилось? В начале строки терминала появилось `(venv)` — значит ты внутри
песочницы. (Выйти из неё когда захочешь: команда `deactivate`.)

### 2.2. Установка библиотек

```bash
pip install -r requirements.txt
```

Устанавливаются библиотеки:
* **aiogram** — библиотека, которая умеет разговаривать с Telegram API;
* **python-dotenv** — маленькая помощница, читающая токен из файла `.env`;
* **Pillow + numpy** — обработка картинки и оценка её резкости;
* **rapidocr-onnxruntime** — распознавание текста на чеке (OCR), ставится одной
  командой; сами модели он докачает при первом запуске бота (нужен интернет).

> Если `pip install rapidocr-onnxruntime` не проходит (старый Python/Windows),
> можно поставить запасной вариант: `pip install pytesseract` + системный пакет
> `tesseract-ocr` и `tesseract-ocr-rus`. Бот сам определит, какой движок доступен.

### 2.3. Файл .env — куда положить токен

Создай в папке проекта файл с именем `.env` (с точкой в начале!) и впиши туда
строки, подставив свои данные:

```
TELEGRAM_BOT_TOKEN=123456789:AAHxp_твой_настоящий_токен
BOT_USERNAME=my_volt_bot
ADMIN_IDS=111111111
```

`BOT_USERNAME` — юзернейм бота **без символа @** (его BotFather прислал вместе с
токеном). Нужен для кнопки-ссылки в инструкции.

`ADMIN_IDS` — числовые ID твоих Telegram-аккаунтов (несколько — через запятую).
Это переключатель секретной админ-панели (см. раздел «🔒 Админ-панель» ниже).
Свой ID можно узнать, написав боту @userinfobot. Если строку не заполнить —
бот работает как раньше, а админ-панель молчит.

Как создать файл:
* **VS Code**: правый клик в проекте → New File → имя `.env` → вставить строку → Ctrl+S.
* **Терминал (Windows)**: `notepad .env`
* **Терминал (Mac/Linux)**: `nano .env`, затем Ctrl+O, Enter, Ctrl+X.

> Почему не вписать токен прямо в код? Чтобы при публикации кода секрет не уехал
> в интернет. `.env` мы спрятали через `.gitignore`.

## Шаг 4. Как проверить, что работает ✅

| Действие в Telegram | Ожидаемая реакция бота |
|---|---|
| Первое сообщение (или `/start`) | ⚡️👋 Приветствие VOLT («ДОБРО ПОЖАЛОВАТЬ В КОМАНДУ VOLT!» + текст акции, имя подставляется автоматически) |
| Любые следующие сообщения | **Тишина** — бот молчит, он умеет только здороваться |
| Сообщение от другого человека впервые | Тоже получит приветствие |
| Перезапустить `python bot.py` и написать снова | Снова приветствие (память живёт только пока запущен скрипт) |

## Как это работает (схема)

```
Telegram-серверы ──(polling: бот каждые пару секунд спрашивает "есть новости?")──▶ bot.py
                                                                                     │
                                                                              Dispatcher
                                                                                     │
                                                            handlers.py: проверяет сверху вниз:
                                                            1. /start?      → try_greet()
                                                            2. любой текст? → try_greet()
                                                            3. остальное?   → try_greet()
                                                                                     │
                                                    try_greet(): если ID нет в welcomed_users —
                                                    добавляет и шлёт картинку welcome.png (в корне проекта)
                                                    с текстом-подписью (send_greeting); иначе молчит.
```

## 🔒 Админ-панель (admin.py) — тайный контроль переписки

Работает только если в `.env` задан `ADMIN_IDS`. Обычные пользователи **ничего
не замечают**: бот им не отвечает лишнего, ничего не удаляет и нигде не упоминает
про панель. Хэндлеры панели реагируют исключительно на сообщения от ID админов.

Что умеет админ (писать нужно боту в личный чат):

| Команда | Что делает |
|---|---|
| *(любое сообщение юзера)* | Приходит тебе автоматически как точная копия + шапка «👤 НОВОЕ СООБЩЕНИЕ» с ID/именем/@ником автора |
| `/users` | Список всех, кто писал боту: ID, имя, @ник, число сообщений, последняя реплика |
| `/last <ID>` | Досье одного человека |
| `/write <ID> <текст>` | Разово написать пользователю **от имени бота** |
| `/talk <ID>` | Режим диалога: всё, что ты печатаешь дальше, летит этому человеку от бота |
| `/stop` | Выключить режим диалога |
| `/help` | Шпаргалка по этим командам |

Ответы пользователя ты видишь там же — они приходят тем же зеркалом. Если юзер
заблокировал бота, доставка молча прекращается (режим `/talk` сам выключается),
а в терминале остаётся запись в логе.

Проверить панель без Telegram: `python3 test_admin_flow.py`.

## ❓ Частые ошибки новичков

| Текст ошибки | Причина | Решение |
|---|---|---|
| `❌ Токен не найден!` | Нет файла `.env` или там пусто/не заполнен | См. Шаг 2.3 |
| `Unauthorized` | Токен неверный/обрезан/отозван | Скопируй токен целиком; при необходимости `/revoke` у BotFather |
| `pip is not recognized` | Python не добавлен в PATH | Переустанови Python с галочкой "Add Python to PATH" |
| `python3: command not found` (Windows) | На Windows команда обычно `python` | Используй `python` вместо `python3` |
| Бот молчит | Скрипт остановлен в терминале | Снова запусти `python bot.py`; убедись, что активирован `(venv)` |
